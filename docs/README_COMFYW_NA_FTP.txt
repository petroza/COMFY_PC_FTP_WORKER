COMFYW — NAHRÁT A HOTOVO

Nahraj tuto složku na FTP jako /comfyw/.
Web otevřeš na https://tvoje-domena.cz/comfyw/

Tlačítko „Můj přístup“ otevře hotovou zabezpečenou instalaci.
Tlačítko „Autoinstalace“ stáhne čistý instalační balíček pro další lidi.

Čistý balíček neobsahuje osobní heslo, osobní token, databázi, cache ani výstupy.
Při instalaci si nový uživatel nastaví vlastní heslo a worker token se vytvoří automaticky.
